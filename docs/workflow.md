# 첫 영상부터 After Effects까지

한 번에 한 단계씩 진행합니다. 각 단계가 끝나면 `work/<shot>/next.md`에 만든 파일,
확인한 것, 남은 문제, 다음 단계 하나를 적습니다. 규칙의 근거는 [rules](rules.md)에 있습니다.

## 작업 폴더

```text
work/<shot>/
  source/            원본 링크 또는 복사본(원본은 수정하지 않음)
  frames/            CFR 작업 프레임 PNG
  contract.json      기준·영역·구간(추적 전에 작성)
  mocha/             Mocha에서 내보낸 코너·추적 데이터
  track/             프레임별 호모그래피(JSON)와 검수 결과
  cleanplate/        기준 프레임, 생성 결과, 정합·색 보정 결과
  patch/             RGBA 패치 시퀀스
  ae/                생성한 JSX, 저장한 AEP
  review/            비교 이미지·영상, report.json
  next.md
```

`work/`는 Git에 올리지 않습니다. 학생 영상·생성 이미지·AEP는 각자의 컴퓨터에만 둡니다.

## 1. 샷 고르기와 준비

- 첫 샷은 짧게(3–8초) 고릅니다. 지울 대상이 **평평한 벽면**에 붙어 있고, 그 벽에
  질감(벽돌·타일·창 배열)이 있고, 사람이 대상을 크게 가리지 않는 영상이 좋습니다.
- ffprobe로 해상도·유리수 FPS·프레임 수를 읽고, FFmpeg로 모든 프레임을 PNG로 뽑습니다.
- 대상이 보이는 첫·끝 프레임과 기준 프레임을 학생과 함께 정합니다.

## 2. contract.json

추적 전에 아래를 정해 저장합니다. 이후 결과를 보고 바꾸지 않습니다.

```json
{
  "source": "work/<shot>/source/clip.mp4",
  "fps": [30000, 1001],
  "frames": [0, 209],
  "visible_frames": [0, 134],
  "reference_frame": 0,
  "working_size": [1920, 1080],
  "remove_quad_reference": [[x, y], [x, y], [x, y], [x, y]],
  "mask_margin_px": 7,
  "gate": {"p95_px": 1.5, "max_px": 3.0}
}
```

## 3. Mocha 추적(학생이 AE에서 직접)

에이전트는 추적 영역을 어디에 그릴지, 무엇을 뺄지 설명하고, 학생이 Mocha에서
추적한 뒤 코너 데이터를 `mocha/`에 저장하도록 안내합니다. 유효 구간과 경고를 기록합니다.

## 4. 검수와 보정(Python)

에이전트가 이 샷용 스크립트를 `work/<shot>/`에 만들어 실행합니다.
1. Mocha 코너 → 프레임별 호모그래피.
2. 독립 검수(지울 영역의 원본 픽셀, ECC·SIFT) → `review/mocha_check.json`.
3. 기준 미달 구간만 ECC 국소 보정 → 다시 독립 검수 → `review/refined_check.json`.

긴 계산은 에이전트의 백그라운드 실행 기능을 쓰고, 같은 계산을 겹쳐 실행하지 않습니다.

## 5. 클린 플레이트와 패치

기준 프레임 한 장으로 클린 플레이트를 만들고 정합·색 보정한 뒤, 지울 영역만
RGBA 패치 시퀀스로 렌더합니다. 알파 밖이 원본과 같은지 확인합니다.

## 6. AE 합성

Python이 만든 JSX를 학생이 AE에서 실행해 원본 + 패치 레이어 프로젝트를 만듭니다.
학생이 렌더하고, 에이전트가 최종 파일을 전체 디코드·독립 검수합니다.

## 다음 확장

스킬을 키울 때는 이번 샷에서 실제로 필요했던 것만 스크립트로 옮깁니다.
예: Mocha 코너 읽기, 독립 검수, ECC 보정, 패치 렌더, AE JSX 생성.
새 샷에서 실패한 양상과 대처는 `next.md`와 규칙 문서에 추가합니다.
